# DIN Islamic AI

A living Islamic university for the Book, the prayer, and the people of this deen.

**Created by Sanni Abdulmateen.**

This campus groups hundreds of study features into colleges — not a wall of buttons:

- **Qur’an College** — mushaf, tafsir, hifz, tajweed
- **Worship College** — live adhan caller, salah times, qiblah compass, deeds tracker, dua, tasbih, Jumu’ah & istikhara, Hajj, Ramadan
- **People of Faith** — prophets, sahabah, sahabiyyah, seerah
- **Living Deen** — 99 Names, Forty Nawawi, zakat & faraid calculators, hijri calendar, glossary, new Muslim path, championship, certificates, ayah journal
- **Knowledge College** — Arabic, studies, history, children, Muslimah
- **Ask DIN** — an Islamic study assistant

## Adhan

When a fard prayer enters, DIN recites the adhan (Fajr has its own recording). Tap the bell once so the browser allows sound. Volume, which prayers to call, and a minutes-before chime live in Salah → Adhan and in Accessibility.

Place optional files in `public/audio/`:

- `adhan.mp3`
- `adhan-fajr.mp3`
- `reminder.wav`

If a local file is missing, the app falls back to a public recording.

## Run locally

```bash
npm install
npm run dev
```
